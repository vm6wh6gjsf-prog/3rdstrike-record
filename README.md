# 3rd対戦記録 v5

- タイトルを「3rd対戦記録」に変更。
- プレイヤーは追加・削除のみ。編集機能を削除。
- 「対戦を記録」欄の中に相手キャラ・勝敗入力を配置。
- 集計戦績の「レポートに記録する」は集計欄の下に配置。
- プレイヤーごとに勝・負・対戦数・勝率を表示。
- 各組み合わせにも勝・負・対戦数・勝率を表示。
- 戦績レポートはタイトル・メモを編集可能。
- レポートごとに削除可能。
- iPhoneホーム画面用アイコンをPNGで用意し、manifestとapple-touch-iconで指定。
- Service Workerのキャッシュ名をv5へ更新。

- 対戦入力カード内に「この内容を記録する」ボタンを配置。
- 対戦数表示を削除し、勝・負・勝率の表示に整理。
- レポートのメモは通常表示。編集時のみ入力可能で、個別のメモ保存ボタンを廃止。
- ホーム画面アイコンをオリジナルデザインのPNGに更新。


## v7 キャッシュ対策
