# 格闘ゲーム戦績記録 PWA

iPhoneのSafariから利用できる、GitHub Pages向けのシンプルな戦績記録アプリです。

## 主な仕様

- 「戦績」「プレイヤー設定」「キャラ設定」の下部固定タブ
- 自分のキャラ、相手プレイヤーを選択
- 1回の記録で相手キャラ＋勝敗を複数行まとめて入力
- キャラクター／プレイヤーは初期状態「不明」のみ
- 追加・編集・削除に対応
- 過去の戦績を一覧表示
- 勝敗数と勝率を自動集計
- データはブラウザのlocalStorageに保存
- PWA対応（ホーム画面に追加可能）

## GitHub Pagesへの公開

1. このフォルダの内容をGitHubリポジトリのルートへpushします。
2. GitHubの **Settings → Pages** を開きます。
3. **Deploy from a branch** を選び、対象ブランチ（通常は `main`）の `/ (root)` を指定します。
4. 公開されたURLをiPhoneのSafariで開き、「共有 → ホーム画面に追加」を選びます。

## 注意

データは端末・ブラウザごとのlocalStorageに保存されます。
GitHubへデータを保存する仕様ではないため、別端末との自動同期は行いません。
