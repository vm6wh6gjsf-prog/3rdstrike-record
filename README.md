# 3rd対戦記録

『ストリートファイターIII 3rd STRIKE』の対戦結果を、iPhoneなどのブラウザから手軽に記録・集計するためのWebアプリです。

## 主な機能

### 戦績入力
1. 「自分のキャラ」を選択します。
2. 「相手プレイヤー」を選択します。
3. 相手キャラを選択し、対戦結果に応じて「勝」または「負」を押します。
4. 同じ相手との複数キャラ戦をまとめて入力したい場合は「＋追加」を使います。
5. 入力が終わったら「この内容を記録する」を押します。

勝・負ボタンは押した回数だけ加算されます。最初の相手キャラ行の「×」は勝敗数を0に戻し、2行目以降の「×」はその行を削除します。

### 戦績
記録した対戦結果を、相手プレイヤー・キャラクターの組み合わせごとに確認できます。
勝数、負数、勝率が自動で集計されます。

不要な組み合わせは「×」で削除できます。
「レポートに記録する」を押すと、その時点の戦績を戦績レポートとして保存します。

### 戦績レポート
保存した時点の戦績を後から確認できます。
レポートには作成日時が記録され、プレイヤー別・キャラクター別の勝敗と勝率を確認できます。

鉛筆ボタンからレポートのタイトルとメモを編集できます。
「×」を押すとレポートを削除できます。

レポートは保存時点のスナップショットなので、その後に通常の戦績を追加・削除しても内容は変わりません。

### プレイヤー設定
対戦相手の名前を追加・削除できます。
初期状態では「不明」が登録されています。

プレイヤーを削除した場合、現在の戦績にあるそのプレイヤー名は「不明」に置き換わります。保存済みの戦績レポートには影響しません。

## データの保存について

戦績、プレイヤー設定、戦績レポートはブラウザのローカルストレージに保存されます。
サーバーやクラウドへの同期は行いません。

ブラウザのWebサイトデータを削除すると記録したデータも消える可能性があるため注意してください。

## iPhoneのホーム画面に追加する方法

1. Safariで公開したアプリを開きます。
2. Safariの共有ボタンを押します。
3. 「ホーム画面に追加」を選択します。
4. 追加された「3rd対戦記録」のアイコンから起動できます。

## GitHub Pagesで公開する場合

このフォルダ内のファイルをGitHub Pagesで公開するリポジトリへ配置してください。
`index.html` がトップページになります。

Service Workerを利用しているため、更新直後に以前の表示が残る場合があります。その場合はSafariでページを再読み込みしてください。
