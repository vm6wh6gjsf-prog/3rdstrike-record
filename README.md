# 3rdストライク戦績記録

- 初期キャラはギルを除く19キャラ。キャラ初期化後も19キャラに戻ります。
- 勝/負ボタンを押した回数をカウントします。
- 自分のキャラ・相手プレイヤー・相手キャラの組み合わせで自動集計します。
- 集計済みの勝数・敗数を直接編集して保存できます。
- 登録日時は保存しません。
- データ削除は「戦績」「プレイヤー」「キャラ」のカテゴリごとです。
- データはlocalStorageに保存します。

GitHub Pagesではリポジトリのルートを公開してください。iPhoneのSafariで公開URLを開き、「共有→ホーム画面に追加」でPWAとして利用できます。
