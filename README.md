# 3rdストライク戦績記録 v4

- 戦績入力のタブ名を「戦績入力」に変更。
- 「戦績レポート」タブを追加。
- 1件目の入力欄の「×」は勝敗カウントを0にリセット。2件目以降の「×」は入力行を削除。
- 集計戦績で相手プレイヤーごとの勝率を表示。
- 各「自分のキャラ / 相手キャラ」組み合わせごとの勝率を表示。
- 組み合わせの削除ボタンは「×」。
- 「x組み合わせ」の表示を廃止。
- 集計戦績の横に「レポートに記録する」ボタンを追加。
- レポートはその時点の集計内容をスナップショットとして保存。
- レポートごとに削除可能。
- レポートごとにメモを保存可能。
- プレイヤー設定は追加・編集・削除可能。
- キャラクターはギルを除く19キャラで固定。
- データはlocalStorageに保存。
