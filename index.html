対戦を記録

戦績

戦績データ削除

登録した戦績だけをすべて削除します。プレイヤー設定と戦績レポートは残ります。

戦績レポート

プレイヤーを追加する

登録プレイヤー

初期状態では「不明」のみ登録されています。

プレイヤー設定の初期化

「不明」以外のプレイヤーを削除します。戦績入力欄での該当する戦績の相手プレイヤーは「不明」になります。

キャラ設定

三本線をドラッグしてキャラクターの並び順を変更できます。

キャラ設定の初期化

キャラクターの並び順を初期状態に戻します。

使い方

『ストリートファイターIII 3rd STRIKE』の対戦結果を、iPhoneなどのブラウザから手軽に記録・集計するためのアプリです。

戦績入力

  1. 「自分のキャラ」を選択します。
  2. 「相手プレイヤー」を選択します。
  3. 「相手キャラ」を選択し、対戦結果に応じて「WIN」または「LOSE」を押します。
  4. 入力が終わったら「戦績に記録する」を押します。

ゴミ箱ボタンを押すと、入力中のWIN・LOSEを0に戻します。

戦績

記録した対戦結果を、相手プレイヤーとキャラクターの組み合わせごとに確認できます。

各組み合わせについて「WIN」「LOSE」「勝率」が自動で集計されます。

不要な組み合わせは「×」から削除できます。

「戦績レポートに記録する」を押すと、その時点の戦績を戦績レポートとして保存します。

戦績レポート

保存した時点の戦績を後から確認できます。

レポートには作成日時が記録され、プレイヤー別・キャラクター別の「WIN」「LOSE」「勝率」を確認できます。プレイヤーごとの最終行には合計戦績が表示されます。

鉛筆ボタンを押すと、レポートのタイトルとメモを編集できます。

「×」を押すとレポートを削除できます。

レポートは保存した時点のスナップショットです。その後に通常の戦績を追加・削除しても、保存済みレポートの内容は変わりません。

プレイヤー設定

対戦相手の名前を追加・削除できます。

初期状態では「不明」が登録されています。

プレイヤーを削除すると、現在の戦績にあるそのプレイヤー名は「不明」に置き換わります。保存済みの戦績レポートには影響しません。

  • 三本線のマークをドラッグして、「不明」を含む登録プレイヤーの並び順を変更できます。

キャラ設定

  • 19キャラクターの一覧を表示します。
  • 三本線のマークをドラッグしてキャラクターの並び順を自由に変更できます。
  • 変更した並び順は、戦績入力などのキャラクター選択欄に反映されます。
  • キャラクターの追加・編集・削除はできません。
  • 「キャラ設定を初期化」で既定の並び順に戻せます。

データの保存

戦績、プレイヤー設定、戦績レポートはブラウザ内に保存されます。サーバーやクラウドへの同期は行いません。

ブラウザのWebサイトデータを削除すると、記録したデータも消える可能性があります。

iPhoneのホーム画面に追加

  1. Safariでアプリを開きます。
  2. Safariの共有ボタンを押します。
  3. 「ホーム画面に追加」を選択します。
  4. ホーム画面に追加された「3rd対戦記録」から起動できます。
